Install

  1. Tap the button and let the download finish.
  2. Open the file. If Android asks, allow your browser to install unknown apps, then go back and tap Install.
  3. If Google Play Protect says "App scan recommended", tap More details, then "Install without scanning". Scan app would send the file to Google.
  4. Updating? Install the new file over the old one. Your notes, tasks and settings stay.

Hodie keeps everything on your phone. Opening this page sends nothing about you. The app is signed with one key, so Android only accepts updates from the same source.
